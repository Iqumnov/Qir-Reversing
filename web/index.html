qir-reversing Quantum Reverse Engineering Platform
PURPOSE

A static analysis and reverse engineering platform for quantum software compiled to LLVM Quantum Intermediate Representation (binary bitcode .bc and textual IR .ll). It decompiles quantum circuits, detects anti-analysis obfuscation, and formally proves functional equivalence.

WORKFLOW
  1. Load: Click Load QIR to open a bitcode (.bc) or IR (.ll) file, or paste assembly directly into the Source editor.
  2. Analyze: Click Analyze to decompile instructions, detect obfuscation patterns, and verify unitary matrix equivalence.
  3. Inspect: Examine findings across the Disassembly, Circuit, Deobfuscation, and OpenQASM viewports.
INTERFACE MODES
  • Source: Raw QIR assembly editor and bitcode file drop zone.
  • Disassembly: Linear instruction stream with decoded qubits, angles, and hex opcodes.
  • Circuit: Interactive topological schematic of quantum wires and scheduled gates.
  • Deobfuscation: Structural audit report, detected anomalies, and minimal canonical circuit.
  • OpenQASM: Decompiled OpenQASM 3.0 code ready for quantum backends and simulators.
LOCAL INSTALLATION & TOOLCHAIN

While this web dashboard provides zero-install client-side analysis, installing the native bundle locally unlocks terminal automation and full IDE integrations:

cargo install --git https://github.com/Iqumnov/Qir-Reversing qir-cli qir-mcp
  • qir (CLI Toolchain): High-throughput local terminal reversing, batch processing, and scriptable pipelines without browser memory or execution limits.
  • qir-mcp (AI Agent Server): Native Model Context Protocol server enabling AI assistants (Cursor, Claude Desktop, Antigravity) to audit and optimize circuits directly.
  • Cutter & Rizin Plugin: Native C-ABI plugin (librz_qir.so) and interactive dock for deep binary and quantum decompilation.
  • qir-gui (Standalone Desktop GUI): Dedicated desktop application with offline capability and native OS file dialogs.
